# Streamlit Community Cloud Deployment Checklist

1. Sign in at Streamlit Community Cloud using the same GitHub account that owns the project repository.
2. Select **Create app** and choose the GitHub repository.
3. Set the branch to `main`.
4. Set the main file path to `tourism_project/deployment/app.py`.
5. In Advanced settings, select Python `3.11`.
6. Deploy the app and wait for the build to finish.
7. Copy the public `streamlit.app` URL into the notebook Output Evaluation section.
8. Take a screenshot of the running app and save it as `tourism_project/evidence/streamlit_app_screenshot.png` before final HTML export.
